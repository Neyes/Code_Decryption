# 터치다운 인생 (Touchdown Life)

미국 고교 풋볼부 10학년(15세)부터 대학 풋볼, NFL 드래프트, 슈퍼볼, 은퇴와 명예의 전당까지 **한 선수의 인생을 키우는 미식축구 커리어 시뮬레이션**입니다.
「자려고 누웠는데 오타니」(KBO 커리어)와 「벤치에서 발롱까지」(축구 커리어)를 분석해 같은 장르로 만들었습니다. 분석 문서는 [`docs/ANALYSIS.md`](docs/ANALYSIS.md)에 있습니다.

## 실행

빌드가 필요 없는 정적 웹앱입니다(ES 모듈). 아무 정적 서버로 폴더를 열면 됩니다.

```bash
cd touchdown-life
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

**바로 열기:** [`touchdown-life.html`](touchdown-life.html)은 모든 JS·CSS를 한 파일에 담은 빌드라서 서버 없이 더블클릭(`file://`)으로도 열립니다.
개발용 `index.html`은 ES 모듈을 쓰므로 서버로 열어야 합니다. 소스를 고친 뒤에는 단일 파일을 다시 만드세요.

```bash
node tools/build-single.mjs   # touchdown-life.html 재생성
node tools/build-single.mjs --artifact out.html   # Claude 아티팩트용(문서 뼈대 없이 내용만)
```

Claude 아티팩트로 열면 진행 내용이 내 Claude 계정의 비공개 저장소(`data/users/<내 id>/`)에도 저장돼서 휴대폰과 PC에서 이어서 할 수 있습니다. 커리어 카드·저장 파일은 다운로드 확인 창을 거쳐 저장됩니다.

밸런스 점검(자동 플레이어로 커리어 N개를 끝까지 돌림):

```bash
node tools/simulate.mjs 120        # 전 포지션
node tools/simulate.mjs 40 QB      # 특정 포지션
TABLE=1 node tools/simulate.mjs 24 # 커리어별 표 출력
```

## 플레이 흐름

1. **선수 만들기 (4단계)**: 모습(피부 톤·머리·바이저) → 이름·등번호·포지션 12개·국적(미국 / 대한민국 유학)·고등학교 21곳 → **플레이 스타일 후보 3장**(모두 OVR 45, 능력치 합 240, 분포만 다름 · `다른 후보 보기`) → **집중 육성 능력치 최대 2개**
2. **시즌 준비**: 이번 목표, 훈련 계획(균형 / 집중 / 회복, 부상 확률 표시), 대학에서는 레드셔트, NFL에서는 뎁스 차트 경쟁자(실제 선수 이름)
3. **시즌 진행**: 시즌을 4구간 + 포스트시즌으로 나눠 진행. 구간 사이에 **선택 카드**(성공 확률 공개, 확률 그대로 굴림), `지금까지 성적`과 시즌 페이스, 부상
4. **시즌 결과**: 성장 공개(능력치 6칸 ▲▼, 급성장, 구간 진입), 역할·출전·팀 성적·평점, 수상과 투표 순위, 목표 달성, 수입, 팔로워
5. **확인할 일**: 시즌 결과 / 결승 문자 중계 / 드래프트 결과 / 전환점 / 새 상품 / **다음 진로**
6. **은퇴**: 커리어 등급(S~D)·점수, 명예의 전당 판정, 링 오브 아너·영구결번, 역대 NFL 기록과 비교, 인생 이야기, 커리어 카드 PNG, 내 은퇴 기록 순위·베스트 라인업

하단 탭: **홈 · 시즌 · 선수 · 기록 · 반응**. 상단: 훈련장(보유 자금), 다크 모드, 설정(저장 파일 내보내기/가져오기).

## 튜토리얼 (선택)

강제로 뜨지 않습니다. 첫 커리어를 만든 직후 한 번 "튜토리얼을 볼까요?"를 묻고(보기 / 건너뛰기, Esc로 닫아도 건너뛰기), 그 뒤로는 다시 묻지 않습니다. 설정 → 튜토리얼 · 조작법, 빅게임 카드의 `조작법 보기 · 연습해 보기`, 업데이트 소식 창에서 언제든 다시 볼 수 있습니다 (`js/ui/guide.js`).

- **4쪽**: 게임 흐름 → 직접 플레이 기본(이동·버튼·작전 고르기·필드 읽기) → **포지션별 키와 능력** → 작전·캐치·난이도·헬스장. 컴퓨터(키보드) / 모바일(터치) 보기를 바꿀 수 있고, 키보드에서는 ←·→(A·D)로 넘기고 Enter 다음, P 연습, Esc 닫기
- **포지션별 키와 능력**: 쿼터백 · 러닝백 · 리시버·타이트 엔드 · 라인맨 · 패스 러셔 · 라인배커·코너백·세이프티 · 키커·펀터. 상황(포켓 / 공을 들었을 때 / 루트 / 공이 올 때 …)마다 어떤 키·버튼이 어떤 기술이고, 무엇을 하며, 어떤 능력치를 쓰는지 표로 보여 줍니다
- **연습해 보기**: 빅게임과 같은 화면의 연습 경기. 고른 포지션으로 끝없이 해 볼 수 있고 기록·성장·저장에 반영되지 않습니다. 조작 안내가 매 스냅 뜹니다
- **조작법 버튼**: 빅게임·연습에서 작전을 고르는 화면의 `조작법`(키보드 H)을 누르면 내 포지션의 키·기술·능력치 표가 그 자리에 뜹니다

## 조작: 컴퓨터 / 모바일

모든 직접 플레이 화면은 **같은 요소**를 보여 주고 **조작만** 기기에 맞게 바뀝니다 (`js/ui/input.js`). 설정 → 조작 방식에서 자동 / 컴퓨터(키보드) / 모바일(터치)을 고를 수 있고, 자동이면 기기(주 포인터가 손가락인지)로 먼저 정한 뒤 실제로 터치하거나 게임 키를 누르면 그 방식으로 바로 바뀝니다. 키는 물리 키 위치로 읽어서 한글 입력 상태에서도 그대로 동작합니다.

| 화면 | 모바일 (터치) | 컴퓨터 (키보드, 마우스 클릭도 가능) |
|---|---|---|
| 실시간 필드 이동 | 왼쪽 아래 아날로그 스틱 | WASD · 방향키 (왼쪽 아래에 눌린 키 표시) |
| 스킬 버튼 1~4 | 오른쪽 아래 버튼 탭 | Space · J · K · L (버튼에 키 표시), 터보는 Shift |
| 시야(확대) | 왼쪽 가운데 `시야` 버튼 탭 | Q 또는 `시야` 버튼 클릭 (가까이 → 보통 → 넓게) |
| 쿼터백 패스 | 리시버나 위쪽 리시버 칩(①~⑤) 탭, 빈 곳 탭은 그 지점으로 | 숫자 키 1~5 = 그 번호 리시버, Space = 가장 빈 리시버 |
| 리시버 패스 콜 | 패스 콜 버튼이나 필드 탭 | Space |
| 작전 고르기 | 카드·선택지 탭 | 숫자 키 1~9 (카드에 번호), Q·E 분류 바꾸기, Enter·Space 스냅·다음 |
| 키커·펀터 | 공 근처에서 위로 쓸어 올리기 (길이 = 파워, 기울기 = 방향) | A·D(←·→) 방향, Space 꾹 눌러 파워 → 초록에서 떼기 (같은 조준선·파워 막대) |
| 헬스장 | 화면 버튼 | Space(연타·탭·꾹) · F·J 또는 A·D(좌우 발) · WASD(콘) · Q·W·E / A·S·D / Z·X·C(표적 9칸), 숫자 키 운동 고르기, Enter 다른 운동, Esc 나가기 |

- **리시버 번호**: 내가 쿼터백이면 스냅 직전부터 던지기 전까지 루트를 뛰는 리시버 머리 위에 1~5번(정렬 왼쪽부터)이 뜨고, 필드 위쪽에 같은 번호의 칩이 나옵니다. 색은 열린 정도(초록 열림 · 노랑 보통 · 빨강 붙음). 번호를 고르면 그 리시버의 움직임을 읽은 리드 패스가 날아가고 그 리시버가 공을 받으러 갑니다
- **새 직접 플레이 기능을 만들 때 규칙**: 두 방식을 함께 만듭니다. 화면 요소(버튼·게이지·표시)는 하나로 두고, 터치 조작과 키 조작을 모두 연결하며, 키보드 모드에서는 요소마다 누를 키를 표시합니다(`inputMode()` · `onInputMode()` · `keyName()`)

## 빅게임 실시간 플레이

시즌마다 라이벌전 하나(고교 홈커밍, 대학 실제 라이벌전 — 더 게임·아이언 볼·레드 리버 라이벌리 등, NFL 디비전 라이벌 나이트 경기)와 포스트시즌 모든 경기에서 멈춥니다. 홈의 빅게임 카드에서 `실시간 직접 플레이`를 고르면 **모든 포지션이 선수를 직접 조작**합니다. 타이밍 미터(QTE)는 없습니다.

- **화면**: 들어가자마자 위에서 내려다본 픽셀 필드(`js/ui/liveplay.js`, 공격은 위쪽으로)가 스냅 전 포메이션과 다운·거리(`2ND & 4`)로 뜨고, 아래에 작전 버튼이 있습니다. 스냅 직전에는 우리 팀 루트가 점선으로(내 루트는 노랑) 보입니다. 플레이가 끝나도 마지막 장면과 결과 글자가 남습니다
- **큰 화면**: 전광판은 한 줄로 줄이고 나머지 화면 전체가 필드입니다. 캔버스 해상도가 화면 비율을 따라가고(세로로 긴 폰일수록 필드가 더 보임), 카메라가 줌(보이는 폭 104~160픽셀)과 좌우 이동으로 내 선수를 따라갑니다. 쿼터백은 패스 전까지 리시버가 모두 보이게 넓게(144) 봅니다. 줌은 1픽셀씩 바뀌어 도트가 흐려지지 않습니다. 작전 버튼은 필드 아래에 반투명 패널로 뜨고, 플레이 중에는 사라집니다
- **카메라와 시야**: 카메라는 내 선수를 따라갑니다(쿼터백은 포켓에서 필드 전체, 던진 뒤에는 공). 공이 뜨거나 다른 선수가 공을 들면 내 선수와 그곳(공이 떨어질 노란 원·볼 캐리어)이 함께 보이도록 자동으로 넓어집니다. 기본 시야는 가까이(폭 192픽셀) · 보통(256) · 넓게(344) 중에서 고르고, 경기 중 왼쪽 가운데 `시야` 버튼(키보드 Q)이나 설정 → 시야에서 바꿉니다. 고른 값은 기기에 저장됩니다. 가로로 넓은 화면에서 재면, 나에게 온 공의 낙하 지점이 화면에 보인 시간이 47% → 100%, 내 리시버가 화면 안에 있던 시간이 86% → 100%로 바뀌었습니다

AI 볼 캐리어는 수비를 보고 열린 길로 꺾고, 태클이 닿을 때 무브(스핀·주크·스티프 암)를 씁니다: 수준이 높을수록 자주 시도하지만(고교 약 40% → NFL 약 54%) 통할지는 태클러와의 능력 차이로 정해지고 수준 높은 수비일수록 덜 통합니다. 느린 리그의 수비는 런을 늦게 읽고(고교 약 1.3초 · NFL 약 1.0초) 블록도 늦게 벗겨 내서, 공격과 수비의 균형은 리그가 달라도 비슷합니다. 쿼터백 봇으로 잰 값(같은 전력끼리, 고교 / 대학 / NFL): 런 캐리당 3.8 / 4.0 / 4.2야드(10야드 이상 런은 160번 중 2 / 15 / 23번), 패스 플레이당 12.1 / 10.6 / 14.2야드, 캐치 후 약 3야드. 팀 전력 차이는 그대로 드러납니다: 고교에서 전력 +6이면 런 5.0야드, −6이면 2.9야드

| 포지션 드릴 | 나타나는 표적 12개를 사라지기 전에 탭 | 포지션 기술(QB 정확도, RB 볼캐리, WR·TE 캐치, CB 커버리지 등) | 3 |

- **하루 제한**: 게임 속 하루(시즌 진행 한 단계, 오프시즌, 시즌 준비)마다 체력 100/120/140, 운동마다 체력 25~30, 같은 운동은 하루 2세트까지. 다음 단계로 진행하면 다시 채워집니다
- **상승량**(`js/engine/gym.js` `finishExercise`): 0.24 × 성적(0~1.25) × 단계 배율(1 / 1.15 / 1.3) × 나이(21세 이하 1.1 · 25세 이하 1 · 29세 이하 0.8 · 그 뒤 0.6) × 남은 여지 × 재능. 소수점 진행도가 1이 되면 능력치 +1. 완벽하게 해도 하루에 능력치 1~2 정도
- 무리하면 누적 피로가 조금씩 쌓이고, 부상 중에는 운동할 수 없어요. 키보드: 스페이스(연타·탭·꾹), F/J(좌우), 방향키

## 연출

시즌 진행 화면(경기별 결과가 하나씩), 성장 공개(숫자가 올라가는 카드), 수상 세리머니(픽셀 불꽃놀이·트로피), 새 시즌 타이틀 카드, 드래프트 지명 발표, 계약서 서명, 부상, 빅게임 VS·결과 화면, 은퇴식(영구결번 배너), 훈련 카드 뒤집기, 선택지 주사위. `prefers-reduced-motion`이면 건너뜁니다.

## 시스템 (주요 수치)

- **능력치**: 포지션마다 보이는 능력치 6개, OVR은 포지션별 가중평균(`js/engine/core.js`의 `POSITIONS`). 포지션 전환 시 능력치를 변환해 다른 포지션 OVR을 계산
- **성장**(`career.js` `grow`): 나이별 기본치 × 재능 속도(숨은 잠재력 62~97, `exp(0.034×(잠재력−80))`) × 출전 비율 × 평점 × 학교·팀 환경 × 훈련 계획 × 집중 육성(×1.5) × 남은 여지 × 정체 22% / 급성장(고교 45%, 대학 30%, NFL 첫 3년 18%). 숨은 특성: 대기만성 16%, 프로의 벽 9%, 부상 체질 18%, 노화 속도
- **노쇠**: 포지션별 전성기(RB 26 · WR/CB/EDGE 28 · OL 30 · QB 32 · K/P 34) 이후 신체 능력부터 하락
- **역할**: 같은 포지션 경쟁자(NFL은 실제 로스터) 대비 내 OVR + 감독 신뢰 보정으로 순위를 매기고, 구간마다 평점·신뢰로 재평가
- **경기 스탯**: 상대 수준 대비 실력(rr)과 출전 비율로 포지션별 라인 생성(패싱·러싱·리시빙·태클·색·INT·패스 디펜스·허용 색·필드골·펀트), 경기 평점 0~100
- **수상**: 시즌 점수 = 평점 × 출전 비중 + 생산량 보너스 + **포지션 보정**(같은 수준이면 포지션과 무관하게 비슷한 점수). 고교(올스테이트, 주 올해의 선수, 고교 올아메리칸), 대학(올 컨퍼런스, 올아메리칸, 포지션상 — 데이비 오브라이언·도크 워커·빌레트니코프·존 매키·아웃랜드·테드 핸드릭스·딕 버트커스·짐 소프·루 그로자·레이 가이 — **하이즈먼**), NFL(프로볼, 올프로 1·2팀, 신인왕, OPOY·DPOY, **MVP**(팀 10승 이상), 재기상, 개인 타이틀, 슈퍼볼 MVP, 월터 페이턴)
- **관계 수치**: 감독 신뢰 · 라커룸 · 팬·언론 · 구단 관계 · 누적 피로. 선택 카드 확률과 역할·계약·부상에 영향
- **훈련장**: 시즌마다 상품 3개 입고·한 시즌에 하나 구매, 스태프(트레이너·포지션 코치·에이전트·영양사·멘탈 코치·홍보 매니저), 개인 시설(헬스장 회원권·웨이트룸·회복실)
- **반응 탭**: 팔로워 그래프, 시즌별 기사와 팬 댓글(모두 가상의 매체·닉네임)
- **리그**: 위키백과 로스터에서 시작해 해마다 나이·성장·노쇠·은퇴·신인 드래프트·이적이 일어나고, 리그 평균이 한쪽으로 쏠리지 않게 맞춤

`tools/simulate.mjs` 120커리어 기준(자동 플레이어): 18세 평균 OVR ≈ 59, 21세 ≈ 72, 최고 OVR 평균 ≈ 80, 드래프트 지명 ≈ 80%, 1라운드 ≈ 20~25%, 프로볼 경험 ≈ 50~57%. QB만 보면 MVP ≈ 20%, 하이즈먼 ≈ 13%.
