# 터치다운 인생 (Touchdown Life)

미국 고교 풋볼부 10학년(15세)부터 대학 풋볼, NFL 드래프트, 슈퍼볼, 은퇴와 명예의 전당까지 **한 선수의 인생을 키우는 미식축구 커리어 시뮬레이션**입니다.
「자려고 누웠는데 오타니」(KBO 커리어)와 「벤치에서 발롱까지」(축구 커리어)를 분석해 같은 장르로 만들었습니다. 분석 문서는 [`docs/ANALYSIS.md`](docs/ANALYSIS.md)에 있습니다.

## 실행

빌드가 필요 없는 정적 웹앱입니다(ES 모듈). 아무 정적 서버로 폴더를 열면 됩니다.

```bash
cd touchdown-life
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

**바로 열기:** [`touchdown-life.html`](touchdown-life.html)은 모든 JS·CSS를 한 파일에 담은 빌드라서 서버 없이 더블클릭(`file://`)으로도 열립니다.
개발용 `index.html`은 ES 모듈을 쓰므로 서버로 열어야 합니다. 소스를 고친 뒤에는 단일 파일을 다시 만드세요.

```bash
node tools/build-single.mjs   # touchdown-life.html 재생성
node tools/build-single.mjs --artifact out.html   # Claude 아티팩트용(문서 뼈대 없이 내용만)
```

Claude 아티팩트로 열면 진행 내용이 내 Claude 계정의 비공개 저장소(`data/users/<내 id>/`)에도 저장돼서 휴대폰과 PC에서 이어서 할 수 있습니다. 커리어 카드·저장 파일은 다운로드 확인 창을 거쳐 저장됩니다.

밸런스 점검(자동 플레이어로 커리어 N개를 끝까지 돌림):

```bash
node tools/simulate.mjs 120        # 전 포지션
node tools/simulate.mjs 40 QB      # 특정 포지션
TABLE=1 node tools/simulate.mjs 24 # 커리어별 표 출력
```

## 플레이 흐름

1. **선수 만들기 (4단계)**: 모습(피부 톤·머리·바이저) → 이름·등번호·포지션 12개·국적(미국 / 대한민국 유학)·고등학교 21곳 → **플레이 스타일 후보 3장**(모두 OVR 45, 능력치 합 240, 분포만 다름 · `다른 후보 보기`) → **집중 육성 능력치 최대 2개**
2. **시즌 준비**: 이번 목표, 훈련 계획(균형 / 집중 / 회복, 부상 확률 표시), 대학에서는 레드셔트, NFL에서는 뎁스 차트 경쟁자(실제 선수 이름)
3. **시즌 진행**: 시즌을 4구간 + 포스트시즌으로 나눠 진행. 구간 사이에 **선택 카드**(성공 확률 공개, 확률 그대로 굴림), `지금까지 성적`과 시즌 페이스, 부상
4. **시즌 결과**: 성장 공개(능력치 6칸 ▲▼, 급성장, 구간 진입), 역할·출전·팀 성적·평점, 수상과 투표 순위, 목표 달성, 수입, 팔로워
5. **확인할 일**: 시즌 결과 / 결승 문자 중계 / 드래프트 결과 / 전환점 / 새 상품 / **다음 진로**
6. **은퇴**: 커리어 등급(S~D)·점수, 명예의 전당 판정, 링 오브 아너·영구결번, 역대 NFL 기록과 비교, 인생 이야기, 커리어 카드 PNG, 내 은퇴 기록 순위·베스트 라인업

하단 탭: **홈 · 시즌 · 선수 · 기록 · 반응**. 상단: 훈련장(보유 자금), 다크 모드, 설정(저장 파일 내보내기/가져오기).

## 빅게임 실시간 플레이

시즌마다 라이벌전 하나(고교 홈커밍, 대학 실제 라이벌전 — 더 게임·아이언 볼·레드 리버 라이벌리 등, NFL 디비전 라이벌 나이트 경기)와 포스트시즌 모든 경기에서 멈춥니다. 홈의 빅게임 카드에서 `실시간 직접 플레이`를 고르면 **모든 포지션이 선수를 직접 조작**합니다. 타이밍 미터(QTE)는 없습니다.

- **화면**: 들어가자마자 위에서 내려다본 픽셀 필드(`js/ui/liveplay.js`, 공격은 위쪽으로)가 스냅 전 포메이션과 다운·거리(`2ND & 4`)로 뜨고, 아래에 작전 버튼이 있습니다. 스냅 직전에는 우리 팀 루트가 점선으로(내 루트는 노랑) 보입니다. 플레이가 끝나도 마지막 장면과 결과 글자가 남습니다
- **큰 화면**: 전광판은 한 줄로 줄이고 나머지 화면 전체가 필드입니다. 캔버스 해상도가 화면 비율을 따라가고(세로로 긴 폰일수록 필드가 더 보임), 카메라가 줌(보이는 폭 104~160픽셀)과 좌우 이동으로 내 선수를 따라갑니다. 쿼터백은 패스 전까지 리시버가 모두 보이게 넓게(144) 봅니다. 줌은 1픽셀씩 바뀌어 도트가 흐려지지 않습니다. 작전 버튼은 필드 아래에 반투명 패널로 뜨고, 플레이 중에는 사라집니다
- **고해상도 도트**: 필드는 1야드 = 6픽셀(예전의 두 배)로 미리 그려 두고(잔디 결·5야드 줄무늬·해시·야드 숫자와 방향 삼각형·미드필드 로고·엔드존 글씨와 줄무늬·파일론·골대·사이드라인 벤치와 코치 박스·엔드라인 뒤 관중석), 선수는 15×19 도트(외곽선 포함 17×21, 라인맨은 어깨가 넓음)를 9가지 동작(서기·달리기 2·3점 자세·던지기·캐치·블록·다이브)으로 그립니다. 공격은 등(등번호), 수비는 앞(페이스마스크·앞번호)이 보이고, 원정 팀은 흰 유니폼 (`js/ui/sprites.js`)
- **플레이북** (`js/ui/playbook.js`, 콘솔 미식축구 게임의 플레이북 구조를 참고해 새로 만든 작전들)
  - 공격 포메이션 8개: 샷건 더블·트립스·번치·엠티, 싱글백 에이스, I 포메이션, 피스톨, 골라인. 플레이 51개를 숏 패스·미디엄·딥 패스·플레이 액션·스크린·런·트릭으로 분류 (스틱·메시·스매시·레벨스·포 버티컬·대거·플러드·Y 크로스·스내그·밀스, 인사이드·아웃사이드 존, 파워 오, 카운터, 토스, 드로, 존 리드, RPO 버블, PA 부트렉, 플리 플리커, 젯 스윕, 엔드 어라운드, QB 스닉 등)
  - 루트 트리 29개(플랫·슬랜트·히치·싯·휩·드래그·앵글·컬·아웃·딥 인·컴백·크로스·코너·포스트·고·페이드·시엄·휠·포스트 코너·슬랜트 앤 고·아웃 앤 업·딥 크로스·버블·스크린 등)
  - 수비 포메이션 6개(4-3, 4-3 언더, 니켈 4-2-5, 다임 4-1-6, 46 베어, 골라인)와 플레이 21개(커버 0·1·2·3·4·6, 탬파 2, 투 맨 언더, 마이크·니켈 코너 블리츠, 파이어 존(DL이 존으로 빠짐), 커버 0 올아웃, QB 스파이, 런 스톱 등)
  - 커버리지 엔진: 딥 존(가장 깊은 리시버 위), 언더 존(들어온 리시버에 붙는 존 매치), 맨(거리 합이 가장 작은 짝, 스냅 전 마크맨 앞으로 정렬), 블리츠·스파이. 스냅 전 셸(딥 세이프티 수)이 보이고 가끔 숨깁니다(디스가이즈)
  - 작전 선택 화면: 분류 탭 + 작전 그림 카드(공격은 루트·1순위·런 길, 수비는 존 색(딥 파랑·훅 노랑·플랫 하늘·컬 보라)·맨 선·블리츠 화살표·내 배정 강조). 추천 탭에는 다운·거리·상대 셸·박스 인원을 본 코치 추천과 한 줄 조언
  - AI: 쿼터백은 작전의 읽는 순서대로 열린 리시버를 찾고(체크다운·버리기·핫 리드), 수비 AI도 같은 점수표로 상황에 맞는 작전을 고릅니다. 런은 라인맨 배정 블로킹(남는 라인맨은 라인배커에게)과 러닝백의 틈 찾기
- **패스·캐치 분류**: 패스는 터치(기본)·불릿(빠르고 낮음, 라인배커 손에 걸릴 수 있음)·로브(높고 느림, 리시버가 달려 들어가 받음). 캐치는 하이포인트(받는 범위↑, 경합에 강함)·안전 캐치(놓칠 확률↓, 캐치 후 느림)·RAC 캐치(받자마자 가속)와 다이빙·사이드라인 토 탭. 결과는 숏(8야드 미만)·미디엄(8~19)·롱(20+) 캐치로 나누고 공중 거리 + 캐치 후 거리, 상대 커버리지를 한 줄로 보여 줍니다
- **아날로그 스틱**: 왼쪽 아래 영역 어디를 눌러도 그 자리에 스틱이 생기고(플로팅), 기울인 만큼 빠르게 달립니다(살짝 기울이면 걷기). 멀티터치라 스틱을 잡은 채 스킬 버튼을 누를 수 있습니다
- **스킬 버튼**(오른쪽 아래, 상황에 따라 바뀜, 원형 게이지로 재사용 대기 표시)
  - 공을 든 선수: 스핀(0.5초, 태클을 떨칠 확률 크게 증가) · 페이크(옆으로 순간 이동, 주변 수비가 민첩성 대결에 지면 물음표를 띄우며 멈칫) · 터보(1.3초 질주) · 스티프 암(다음 태클을 피지컬로 밀어냄)
  - 루트를 뛰는 리시버: 페이크(마크맨을 루트 능력으로 속임) · 패스 콜(조금이라도 열려 있으면 쿼터백이 바로 나에게) · 터보, 공이 가까이 뜨면 하이포인트·안전·RAC 캐치 중 선택
  - 쿼터백(포켓): 패스(가장 빈 리시버) · 펌프 페이크(플레이당 2번, 수비수들이 판단 대결에 지면 멈칫) · 스핀(색 피하기) · 패스 종류 전환(터치·불릿·로브). 필드를 탭하면 그 지점으로, 리시버 근처를 탭하면 그 리시버 앞으로 리드 패스
  - 커버 수비(내 배정이 스냅 전에 노란색으로 표시): 잼(출발 직후 붙은 리시버를 밀어 멈춤) · 다이브 태클(태클 범위 증가, 빗나가면 넘어져 잠시 못 일어남) · 터보, 공이 가까이 뜨면 가로채기(인터셉트 노림) 또는 쳐내기(확실한 패스 디펜스)
  - 패스 러셔: 스핀 무브·스윔(블로커에 묶였을 때 민첩성·손기술로 빠져나감) · 터보 / 라인맨: 펀치(붙은 러셔를 밀쳐 멈춤) · 버티기(1.4초 동안 떨쳐 내지 못함)
  - 키보드: 방향키 이동, 스페이스·Z·X·C·V로 버튼 1·1·2·3·4
- **쿼터백**: 플레이북에서 작전을 고르면 리시버들이 루트를 뛰고, 원하는 곳에 던집니다. 스냅 전 상대 셸을 읽어 작전을 고를 수 있습니다. 핸드오프나 캐치 뒤에는 볼 캐리어를 조작
- **리시버·러닝백**: 내 루트는 내가 뜁니다. 수비를 떼어 내면 AI 쿼터백이 던지고, 노란 원(공이 떨어질 곳)으로 가서 받습니다. 조금 멀면 다이빙 캐치
- **라인맨**: 레프트 태클로 뛰며 빨간 화살표가 붙은 맞상대 러셔를 막습니다. 러셔는 정해진 바깥 레인으로 돌다가 가끔 안쪽으로 꺾고, 이 러셔는 다른 블로커가 도와주지 않습니다. 라인맨으로 뛸 때는 AI 쿼터백이 공을 더 오래 들고 있어 블로킹이 결과를 가릅니다(AI 시험: 손을 떼면 패스 플레이 대부분 색, 완벽히 막으면 색 0). 오래 막으면 팬케이크, 놓치면 색 허용이 기록됩니다
- **수비**: 수비 콜(맨투맨, 존 커버 3, 블리츠)을 고르고 내 수비수를 움직여 커버하다 노란 원으로 가면 인터셉트·패스 디펜스, 볼 캐리어에 닿으면 태클. 엣지 러셔·DT는 블로커를 돌아 쿼터백을 노립니다
- **키커·펀터** (`js/ui/kickplay.js`): 키커 뒤에서 내려다본 원근 화면(골대, 관중석, 조명탑, 라인과 러셔). `스냅!` 뒤 러셔가 오기 전(필드골 3.2초, 펀트 2.8초)에 공에서 위로 쓸어 올립니다. 끈 길이가 파워(초록 구간에서 놓기, 너무 세면 빨강으로 휘어짐), 기울기가 방향, 바람은 화면 왼쪽 위 화살표를 보고 직접 계산. 공은 3차원으로 날아가 골대 사이·크로스바 위를 지나야 성공하고, 기둥에 맞으면 `DOINK!`. 펀트는 카메라가 공을 따라가며 상대 20야드 안(금색 구역)·사이드라인 밖·터치백·페어 캐치·리턴을 판정합니다. 킥력·정확도·펀트·일관성·침착함(마지막 킥) 능력치가 비거리와 흔들림을 정합니다
- **흐름**: 4번째 다운 결정(고 / 필드골 / 펀트), 터치다운 뒤 PAT·2점 컨버전(실시간), 상대 포메이션 힌트(70% 정확)
- **AI**: 맨 커버리지는 반 박자 늦게 따라오고, 세이프티는 깊은 공에 반응하며, 패스 러셔는 포켓 시간(라인 전력 차이로 2.2~4.6초)을 따릅니다. 원정 팀은 흰 유니폼
- 결과(득점, 스탯, 평점)가 엔진으로 넘어가 시즌 기록·수상·성장에 그대로 반영됩니다
- 개발용: `tools/live-preview.html?pos=QB&concept=flood`(한 플레이 미리보기, `pos=OL|K|P`도 됨, `&auto=1`이면 바로 스냅), `tools/live-balance.html?pos=CB&n=80`(AI끼리 빠르게 돌려 결과 분포 확인, `&assist=1`은 손을 뗐을 때 AI가 완벽하게 돕는 정도)

## 연출

시즌 진행 화면(경기별 결과가 하나씩), 성장 공개(숫자가 올라가는 카드), 수상 세리머니(픽셀 불꽃놀이·트로피), 새 시즌 타이틀 카드, 드래프트 지명 발표, 계약서 서명, 부상, 빅게임 VS·결과 화면, 은퇴식(영구결번 배너), 훈련 카드 뒤집기, 선택지 주사위. `prefers-reduced-motion`이면 건너뜁니다.

## 시스템 (주요 수치)

- **능력치**: 포지션마다 보이는 능력치 6개, OVR은 포지션별 가중평균(`js/engine/core.js`의 `POSITIONS`). 포지션 전환 시 능력치를 변환해 다른 포지션 OVR을 계산
- **성장**(`career.js` `grow`): 나이별 기본치 × 재능 속도(숨은 잠재력 62~97, `exp(0.034×(잠재력−80))`) × 출전 비율 × 평점 × 학교·팀 환경 × 훈련 계획 × 집중 육성(×1.5) × 남은 여지 × 정체 22% / 급성장(고교 45%, 대학 30%, NFL 첫 3년 18%). 숨은 특성: 대기만성 16%, 프로의 벽 9%, 부상 체질 18%, 노화 속도
- **노쇠**: 포지션별 전성기(RB 26 · WR/CB/EDGE 28 · OL 30 · QB 32 · K/P 34) 이후 신체 능력부터 하락
- **역할**: 같은 포지션 경쟁자(NFL은 실제 로스터) 대비 내 OVR + 감독 신뢰 보정으로 순위를 매기고, 구간마다 평점·신뢰로 재평가
- **경기 스탯**: 상대 수준 대비 실력(rr)과 출전 비율로 포지션별 라인 생성(패싱·러싱·리시빙·태클·색·INT·패스 디펜스·허용 색·필드골·펀트), 경기 평점 0~100
- **수상**: 시즌 점수 = 평점 × 출전 비중 + 생산량 보너스 + **포지션 보정**(같은 수준이면 포지션과 무관하게 비슷한 점수). 고교(올스테이트, 주 올해의 선수, 고교 올아메리칸), 대학(올 컨퍼런스, 올아메리칸, 포지션상 — 데이비 오브라이언·도크 워커·빌레트니코프·존 매키·아웃랜드·테드 핸드릭스·딕 버트커스·짐 소프·루 그로자·레이 가이 — **하이즈먼**), NFL(프로볼, 올프로 1·2팀, 신인왕, OPOY·DPOY, **MVP**(팀 10승 이상), 재기상, 개인 타이틀, 슈퍼볼 MVP, 월터 페이턴)
- **관계 수치**: 감독 신뢰 · 라커룸 · 팬·언론 · 구단 관계 · 누적 피로. 선택 카드 확률과 역할·계약·부상에 영향
- **훈련장**: 시즌마다 상품 3개 입고·한 시즌에 하나 구매, 스태프(트레이너·포지션 코치·에이전트·영양사·멘탈 코치·홍보 매니저), 개인 시설(웨이트룸·회복실)
- **반응 탭**: 팔로워 그래프, 시즌별 기사와 팬 댓글(모두 가상의 매체·닉네임)
- **리그**: 위키백과 로스터에서 시작해 해마다 나이·성장·노쇠·은퇴·신인 드래프트·이적이 일어나고, 리그 평균이 한쪽으로 쏠리지 않게 맞춤

`tools/simulate.mjs` 120커리어 기준(자동 플레이어): 18세 평균 OVR ≈ 59, 21세 ≈ 72, 최고 OVR 평균 ≈ 80, 드래프트 지명 ≈ 80%, 1라운드 ≈ 20~25%, 프로볼 경험 ≈ 50~57%. QB만 보면 MVP ≈ 20%, 하이즈먼 ≈ 13%.
