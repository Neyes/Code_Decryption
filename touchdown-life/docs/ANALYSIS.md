## 1. wannabeohtani.com — 「자려고 누웠는데 오타니」 (KBO 커리어)

### 1.1 기술 구조
| 항목 | 내용 |

- **선수 생성 4단계**: ① 이름과 학교(이름, 등번호, 투타, 시작 국가 한국/일본/미국, 출신 고교 목록 70여 개) ② 모습(얼굴 24종, 응원팀 유니폼) ③ 포지션(P, C, 1B, 2B, 3B, SS, OF) ④ 육성 스타일(타자: 균형형, 장타형, 교타형, 주루형, 수비형 / 투수: 구속형, 제구형, 체력형)

### 1.3 능력치 모델 (`abilities.js`)
- **스카우팅 툴**(성장하는 값): 타자 6개(컨택, 파워, 주력, 어깨, 수비, 선구안), 투수 4개(구위, 제구력, 커맨드, 딜리버리)
- **세부 능력**은 툴의 고정 가중합. 예: `삼진 회피 = 컨택 .7 + 선구안 .3`, `실전 파워 = 파워 .65 + 컨택 .35`
- 엔진 값(15~99)을 **20–80 스카우팅 등급**으로 바꿔 표시: `62 → 50(KBO 평균)`, 62 이상은 1:1, 그 아래는 압축
- 등급 구간 이름: 74 메이저리그 탑급 / 60 KBO 탑급 / 50 KBO 평균 / 41 고교 상위권 / 20 고교 평균
- 툴마다 **성장 창**이 다름: 파워 16–21세, 주력은 고교 때 거의 완성, 선구안은 20대 후반까지

### 1.4 성장 모델 (`engine.js`)
- **잠재력(potential)**은 로지스틱 분포 한 번 추첨, 64~95. 88+ 약 19%, 75 이하 약 22%
- 재능은 **상한이 아니라 성장 속도**: `talentSpeed = exp(0.015~0.03 × (potential − 81.5))`. 모든 툴이 99까지 갈 수 있지만 99에 가까울수록 느려짐(`room = 99 − 값`)
- 나이 구간(16–18/19–21/22–24/25–27/28+)별 기대 성장치 표 `WINDOWS`, 쇠퇴 시작 나이와 연간 하락폭
- 툴마다 시즌 롤: **정체 / 보통 / 급등**. 급등(breakout)은 시즌당 최대 1개, 확률은 고교 50%, 대학·상무 30%, 프로 첫 3년 20%, 이후 4%(숨은 **대기만성** 특성이면 12%)
- 숨은 특성: **대기만성**(시드 해시 18%, 대졸 30%), **프로의 벽**(8%, 프로 성장 속도 절반), `agingRate`(노화 속도 0.8~1.25)
- **커리어 하이 시즌**: 전성기에 가끔 평소보다 6~10점 높게 뛰는 시즌, 드물게 리그 엘리트급 '인생 시즌'

### 1.5 시즌 진행과 선택 카드 (`events.js`, `events/*.js`)
- 시즌 달력을 8구간으로 나누고, 그중 1·3·5·7구간 끝에서 카드를 뽑음. **시즌당 카드 수는 나이에 따라 줄어듦**(24세 이하 3장, 25~35세 2장, 이후 1장, 첫 시즌은 1장)
- 카드 형식: `eyebrow`(예: "고교 · 전국대회"), `title`, `body`, 선택지 1~3개. 선택지마다 `성공 확률 N%`가 표시되고, 확률은 `base + 관계 수치 × per`
- 성공/실패마다 효과: 관계 수치(**감독 신뢰, 라커룸, 팬·언론, 구단 관계, 대표팀 관계, 만성 부상**), 능력치 증감, 시즌 보정(출전 기회, 성적, 부상 위험), 플래그(다음 카드 조건)
- 카드 조건(`when`): 단계, 레벨, 나이 범위, 포지션, 지위(백업 이하 등), 시즌 구간, 현재 폼(slump/hot/record), 플래그
- **폼 판정**: 같은 레벨의 자기 지난 시즌 또는 리그 평균 대비 OPS/ERA로 슬럼프·상승세·기록 페이스

### 1.6 커리어 단계
고교(1~3학년, 주말리그·황금사자기·청룡기·봉황대기) → KBO 드래프트(11라운드) 또는 대학 진학·육성선수 → 퓨처스/1군 → 병역(상무, 현역, 아시안게임 금메달·올림픽 동메달 이상 체육요원) → FA(일반 8시즌, 대졸 7시즌) / 포스팅(7시즌) → MLB·NPB → 은퇴. 일본·미국 시작 루트도 있음(고시엔, NCAA, JUCO, 마이너리그)

### 2.2 화면 구조
- **상단바**: 제목, `💸 개발자 서버비 내주기`, 언어, 공지, 인스타그램, X, 설정
- **하단 탭 5개**: `홈` · `반응` · `시즌` · `선수` · `기록`
- **홈**: 이름·소속·나이, 종합 능력치(지난 시즌 대비 +N), 통산 경기·골·도움, **확인할 일** 목록(시즌 결과가 나왔어요 / 전환점이 찾아왔어요 / 다음 진로를 정할 차례예요 / 집중 육성 중 / 새 상품이 입고됐어요), `지금 은퇴하기`, 시즌 진행 버튼(`고2 시즌 보내기`)
- **시즌**: 다음 이야기(진로 카드), 고를 수 있는 길 N개, 시즌 요약, 국가대표 일정(실제 대회 날짜), 전체 시즌 목록
- **선수**: 능력치 6개(집중 육성은 파란색, 지난 시즌 대비 +N), 약발 훈련, 선수 정보(소속, 단계, 연봉, 추정 가치, 병역)
- **기록**: 트로피(우승, 개인상), 시즌/커리어 통산/대회별 기록
- **반응**: 기사 1개 + 팬 댓글(닉네임 마스킹 `9too****`, 성향 태그 `드립/훈훈/열광`, 출처 `네이버 스포츠 댓글/인스타그램 댓글`, 좋아요 수)

### 2.3 선수 생성 (직접 플레이로 확인)
1. 아바타 고르기 → 2. 이름, 등번호, 포지션(ST, LW, RW, CAM, CM, CDM, LB, CB, RB, GK), 주발, 국적, 시작 국가, 고등학교 → 3. **플레이 스타일 후보 3장**(예: 스트라이커 → 타깃맨, 세컨드 스트라이커, 포처). **세 후보 모두 OVR 45, 여섯 능력치 합 240**, 분포만 다름. `다른 후보 보기`로 재추첨 → 4. **집중 육성 능력치 최대 2개**(훨씬 빨리 자라고, 전환점에서만 바꿀 수 있음) → 요약 카드 → `고1 시즌 시작`

### 2.4 시즌 진행
- 버튼 한 번에 시즌 전체를 시뮬레이션(애니메이션 + `건너뛰기`)
- 결과 시트: "고1 시즌이 끝났어요 · 종합 능력치가 48이 됐어요", 출전(경기·선발), 골·도움, 평균 평점(6.43), 능력치 변화, **대회 결과**(실제 대회명: K리그 주니어 U18 전·후반기, 부산MBC 전국고교대회, 협회장배, K리그 U18 챔피언십, 왕중왕전 → 순위·라운드), 시즌의 순간, 언론·팬 반응
- **전환점 카드**: 일러스트 + 제목 + 선택지 2개(설명 한 줄) + `나중에 생각하기`. 예: "새로운 가능성을 발견한 코치 → 새로운 가능성에 도전한다 / 현재 강점부터 확실히 한다"
- **진로 카드**: "고3 전반기 종료 · 구단 제안 — 학교에서 후반기 준비(고교 잔류) / FC 서울 준프로 계약 · 연봉 3,000만 원". 각 길은 상세 시트에서 `선택하기`

### 2.5 핵심 로직 (번들에서 확인한 코드)
```js
// 역할과 출전: 내 능력치 − 팀 기준치 차이로 선발 확률·역할이 정해짐
ROLE_LABELS = {key:"핵심 선수", starter:"1군 주전", rotation:"1군 준주전", backup:"1군 후보", reserve:"육성팀 배정"}
ROLE_TRUST  = {key:88, starter:72, rotation:53, backup:34, reserve:16}
diff ≤ −18 → reserve(선발 0.1%) … diff ≤ −4 → rotation(선발 28%) … 그 이상 → key(선발 97%)
// 시즌 중 8경기마다 신뢰도(trust)로 역할 재평가. 평점 6.6 기준으로 신뢰도가 오르내림
```
- 역할 승격에는 출전 경기, 선발 수, 출전 시간, 평균 평점 조건이 붙음(예: 핵심 선수는 22경기 이상, 평점 7.1 이상)
- **성장**: 나이(10대 후반~20대 초반이 가장 큼), 출전 시간, 활약(평점), 건강, 숨은 성장 특성. 잠재력은 상한, 성인이 된 뒤 출전이 적으면 도달 못 함
- **이적**: 제안서 역할(핵심/주전/준주전/후보), 임대 6개월·1년·2년, 이적 요청, **태업**(평판 하락, 한 시즌 날릴 수 있음), 라이벌 이적·친정 복귀는 '인생 이야기'에 기록
- **계약**: 연봉은 역할 × 구단 규모, 30대엔 인상 폭 감소, 사우디·중국·MLS 제안, 고향팀 복귀 제안
- **발롱도르**: 그 시즌 활약 + 큰 트로피(월드컵, 유로, 코파, UCL) 비중 큼, 포지션 공정, 2~4위는 트로피 경쟁에서 아깝게 밀린 시즌
- **포지션 전환**·**약발 훈련** 제안, 포지션별 전성기 길이(윙어 30대 초 급락, CB·GK 30대 중반까지)
- **레전드·영구결번**: 한 구단에서 오래 뛰며 우승·발롱도르·기록 경신
- **은퇴**: 기량 하락 시 구단이 권유, 계약 만료 후 제안이 없으면 은퇴. 인생 이야기, 커리어 카드, 빅5 리그 역대 기록과 비교
- **상점**: 시즌마다 상품 3개 입고(프리미엄 침대 패스↑ 3억, 오픈카 스피드↑ 7억, 전용기 1200억…), 한 시즌에 하나만 구매, 비쌀수록 많이 오름
- **결승 중계**: 메이저 대회·대륙 클럽 대회 결승에 내가 뛰면 중계 화면
- **랭킹**: 발롱도르 횟수 → 최고 OVR → 개인상 수 → 공격포인트, 부문별(공격/미드/수비/GK/원클럽맨), 4-3-3 오늘의 베스트 일레븐

## 3. 두 게임의 공통 설계 원칙
1. **한 선수의 인생 한 번**: 고교 1학년 → 프로 → 은퇴. 시즌 단위 턴
2. **실제 세계를 출발점으로**: 실제 팀·학교·대회·규정·일정, 단 능력치와 결과는 게임 모형이라고 명시
3. **숨은 재능 + 보이는 선택**: 잠재력·대기만성·벽은 숨기고, 플레이어는 출전 시간·팀 선택·카드 선택으로 결과를 바꿈
4. **확률을 보여 준다**: 선택지 성공 확률을 공개하고, 시드로 고정해 재시도 꼼수를 막음
5. **보상 연출**: 성장 공개 모달, 트로피, 팬 반응, 결승 중계, 은퇴 카드
6. **모바일 우선, 가입 없음, 로컬 저장**
